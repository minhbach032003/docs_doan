|Inventory Staff|
start
:Identify defective, damaged,\nexcess or non-conforming goods;
:Check product, lot,\nwarehouse and location;
:Look up related Purchase Order\nand Goods Receipt;
:Enter return quantity\nand return reason;
:Create Supplier Return Request;

|System|
:Validate purchase reference,\nlot and return quantity;

if (Return request valid?) then (Yes)

    :Create Supplier Return Request;
    :Set status to Pending Review;

else (No)

    :Reject invalid Return Request;
    :Display validation errors;

    |Inventory Staff|
    :Review invalid return data;

    stop

endif


|Accountant|
:Review Purchase Order,\nGoods Receipt and invoice;
:Contact supplier\nthrough external channel;
:Record supplier response;

if (Supplier accepts return?) then (Yes)

    :Record agreed return terms;
    :Record return method\nand expected return date;

else (No)

    :Record supplier rejection\nand follow-up note;

    |System|
    :Set Supplier Return Request\nas Supplier Rejected;
    :Notify Inventory Staff\nand Store Owner;

    stop

endif


|System|
:Submit Supplier Return Request\nfor approval;

|Store Owner|
:Review return reason,\nquantity and supplier agreement;

if (Approve supplier return?) then (Yes)

    |System|
    :Set Supplier Return Request\nas Approved;
    :Notify Inventory Staff;

else (No)

    |System|
    :Set Supplier Return Request\nas Rejected;
    :Record rejection result;
    :Notify Inventory Staff\nand Accountant;

    stop

endif


|Inventory Staff|
:Review approved Return Request;
:Locate goods by warehouse,\nlot and storage location;
:Pick approved goods;
:Check actual return quantity;

|System|
:Compare actual quantity\nwith approved quantity;

if (Quantity discrepancy?) then (Yes)

    |Inventory Staff|
    :Record actual quantity;
    :Record discrepancy reason;

    |System|
    :Calculate revised\nreturn quantity;

    |Store Owner|
    :Review revised quantity;

    if (Approve revised quantity?) then (Yes)

        |System|
        :Update approved\nreturn quantity;

    else (No)

        :Set Return Request\nto Adjustment Required;
        :Notify Inventory Staff\nand Accountant;

        stop

    endif

else (No)

    |System|
    :Keep approved\nreturn quantity;

endif


|Inventory Staff|
:Prepare return shipment;
:Check product, lot,\nquantity and packaging;
:Confirm physical handover;
:Confirm Supplier Return Issue;

|System|
:Validate return issue;
:Create Return Goods Issue Note;
:Deduct returned quantity\nfrom warehouse stock;
:Update inventory history;
:Set Supplier Return Request\nas Dispatched;


|Accountant|
:Track supplier return\noffline;
:Receive supplier acknowledgement;
:Record acknowledged quantity;
:Attach supporting documents;

|System|
:Compare acknowledged quantity\nwith dispatched quantity;

if (Acknowledged quantity matches?) then (Yes)

    :Confirm supplier\nreturn acknowledgement;

else (No)

    |Accountant|
    :Record acknowledgement discrepancy;
    :Contact supplier externally;
    :Record resolution result;

    |System|
    :Validate resolved quantity;

    if (Discrepancy resolved?) then (Yes)

        :Update accepted\nreturn quantity;

    else (No)

        :Set Supplier Return Request\nto Pending Reconciliation;
        :Notify Accountant\nand Store Owner;

        stop

    endif

endif


|Accountant|
:Review final return result;
:Review original supplier invoice;
:Record supplier credit,\npayable adjustment or refund;

|System|
:Update supplier payable balance;
:Link financial adjustment\nto Supplier Return Request;
:Update purchase reconciliation;

:Notify related staff;

stop
