@startuml
title 2.4 Customer Return and Reverse Logistics (BF-04)

scale 1400 width

skinparam shadowing false
skinparam defaultFontName Arial
skinparam activityBorderColor #666666
skinparam activityBackgroundColor #FDFDFD
skinparam activityDiamondBackgroundColor #FFF4D6
skinparam activityDiamondBorderColor #888888
skinparam activityArrowColor #666666

|Sales Staff|
start
:Receive customer return request
through offline channels;
:Look up original Sales Order
and delivery information;
:Review returned products,
quantities, and return reasons;
:Create Customer Return Request;

|System|
:Validate original Sales Order;
:Check delivered quantities,
previously returned quantities,
and return eligibility;

if (Return request valid?) then (Yes)
    :Save Customer Return Request;
    :Update request status to Pending;
else (No)
    :Display validation errors;

    |Sales Staff|
    :Review errors and clarify
    return information with customer;
    stop
endif

|Sales Staff|
:Record expected return date
and receiving warehouse;
:Arrange return of goods
to the designated warehouse;

|Inventory Staff|
:Review pending return request;
:Receive physical returned goods;
:Check product, quantity, lot,
packaging, and physical condition;
:Record inspection results;

|System|
:Compare actual returned goods
with original Sales Order
and Customer Return Request;

if (Receiving discrepancy found?) then (Yes)
    |Inventory Staff|
    :Record quantity discrepancy,
    damaged goods, or wrong products;
    :Provide inspection remarks;
endif

|Inventory Staff|
:Submit return inspection results;

|Store Owner|
:Review Customer Return Request
and inspection results;

if (Approve returned goods?) then (Yes)
    :Confirm accepted products
    and return quantities;

    |System|
    :Record approved return quantities;
    :Update return request status
    to Approved;

    |Inventory Staff|
    :Confirm receipt of accepted goods;
    :Assign receiving warehouse
    and storage location;

    |System|
    :Generate Customer Return
    Goods Receipt Note;
    :Update inventory quantities
    by warehouse, lot, and location;
    :Move received goods
    to Pending Inspection;

    |Inventory Staff|
    :Classify returned goods
    according to inspection results;

    if (Goods suitable for resale?) then (Yes)
        |System|
        :Move approved quantities
        to Available Stock;
    else (No)
        |System|
        :Move affected quantities
        to Quarantine or Damaged Stock;
    endif

    |Accountant|
    :Review approved return
    and related sales documents;
    :Record applicable receivable
    adjustment or refund information;

    |System|
    :Update financial records;
    :Update inventory transaction history;
    :Update return request
    status to Completed;

    |Sales Staff|
    :Review completed return;
    :Inform customer of return result;

else (No)
    |System|
    :Update return request
    status to Rejected;
    :Record rejection reason;

    |Sales Staff|
    :Review rejection result;
    :Inform customer of rejection
    and arrange handling of goods;

    |Inventory Staff|
    :Keep rejected goods separate
    pending return to customer;
endif

|System|
:Update customer return history;
:Update related Sales Order records;
:Update inventory and sales reports;
:Notify relevant staff;

stop
@enduml
